# QA-001 — Synthetic 90-day dataset for the second LifeOS account

Status: IMPLEMENTED (offline generator, validation, tested API adapters). No import was executed.
The remote apply is pending an approved token mechanism and an explicit run authorisation by the owner.

Branch: `feature/qa-001-synthetic-dataset`. Baseline: `main` @ `5f1ffbc`. Issue: #40.

## Scope

Tooling only, under `tools/qa-dataset/`: a deterministic generator, a manifest with expected assertions,
consistency checks, a CLI (offline dry-run by default), import adapters for Finance, Nutrition and Journal
through the existing authenticated API, resume and reconciliation, tests and documentation. Operator guide:
[tools/qa-dataset/README.md](../../../tools/qa-dataset/README.md).

Not changed: Domain, Application, Infrastructure, API, Contracts, App, migrations, `lifeos-ai`, deployment,
Render/Neon/Firebase/cron jobs, and ADR-008. No packages were added.

## Decisions

| Decision | Reason |
| --- | --- |
| Python standard library, run with `uv run --no-project` | Already used by the repository (`tools/ai-evals`, Python 3.14). No dependency to lock or audit. `unittest` avoids a test-only package. |
| Location `tools/qa-dataset/` | As required by the issue. An interrupted earlier attempt lived in `tools/synthetic-data/` and was moved and completed here. |
| Seed + **reference date** (window = 90 days before it) | The dataset is fixed in time and only historical days are importable. Defaults: seed 40, reference 2026-08-30. |
| Fixed synthetic offset +02:00 | Local times and `utcOffsetMinutes` stay consistent. Every instant is sent as explicit UTC. |
| Text markers `[qa001-…]` for reconciliation | The API has no client keys or idempotency headers, and adding them is out of scope. |
| Categories and account mapped in a local config | Category or account creation is not part of the dataset. The operator maps existing owned resources. Several keys may share one category. |
| Nutrition values via `PUT …/nutrition` with `UserAdjusted` | This is the existing manual path. AI estimation is never called. |
| Budgets sized from the generated non-travel spend + 10% | Only the trip month exceeds its budget, for any seed. Validation enforces it. |
| Rules end in the last dataset month | The test account does not accumulate Due occurrences for later months. |
| Remote targets need `--allow-remote` + HTTPS + approval binding | Loopback is the default. The future second-account run needs no code change, only explicit opt-in. |
| No automated clean-up | Deletion is destructive. The README documents a human-reviewed procedure. |

## Gym (ADR-008)

The 24 historical workouts are offline-only fixtures (`importStatus: not_importable_via_public_api`). The
Gym endpoints start sessions at the server clock, so there is no compliant way to record past sessions.
QA-001 neither backdates them nor writes them as today's sessions. The importer never calls a Gym route,
and a test asserts this. Follow-up proposal: [GYM-HIST-001](../gym/GYM-HIST-001.md).

## Contract notes found while completing the earlier attempt

- `GET /api/transactions` returns the type as `type`, not `transactionType`. The earlier reconciliation read
  the wrong field. This is fixed and covered by the fake API, which mirrors the real contracts.
- `PUT /api/budgets/...` answers 204 with an empty body. The client now accepts empty bodies.
- `GET /api/transactions` and the budget read use half-open UTC ranges. The budget read must match the local
  month boundaries.
- Recurring `confirm`/`skip` and planned `confirm`/`cancel` are idempotent per logical month or item, so
  they are safe to retry. Creates are not.
- Access tokens last 15 minutes. A long run may stop with 401 and resume after a new token.

## Validation

- `cd tools/qa-dataset; uv run --no-project python -m unittest`: dataset determinism, invariants and
  violation cases; CLI dry-run without network; approval and target guards; complete import in dependency
  order; rerun and state loss without duplicates; 400/401/403/409/429 and transport failures; timeout after
  commit; uncertain creates never re-posted; uncertain idempotent actions retried; remote conflicts abort
  before any write; no token or email in output; whoami read-only.
- Live AI calls and Journal embedding are not part of any test.
